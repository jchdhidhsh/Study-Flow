## 3. 分支命名规范

```
<类型>/<功能>-<简短描述>

类型前缀：
- feat: 新功能
- fix: 缺陷修复
- refactor: 重构
- docs: 文档更新
- test: 测试相关
- chore: 构建/工具

示例：
feat/tag-classification
feat/tag-filter
fix/reminder-null-check
refactor/reminder-strategy
docs/update-contract
test/tag-service
```

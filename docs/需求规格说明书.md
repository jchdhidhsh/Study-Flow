# StudyFlow 学习任务管理系统 - 软件需求规格说明书

---

## 1. 用户角色

| 角色 | 描述 |
|------|------|
| 个人学习者 | 系统的唯一使用者，包括学生、自学者等。可管理自己的学习任务、查看个人学习数据，无多用户、多角色需求。 |

---

## 2. 用户故事

| 编号 | 用户故事（As a... I want to... So that...） |
|------|------------------------------------------|
| US-01 | 作为一个 **学生**，我想要 **创建学习任务并设置截止时间**，以便 **明确每项学习的完成期限**。 |
| US-02 | 作为一个 **学生**，我想要 **为任务设置高/中/低优先级**，以便 **合理安排学习顺序**。 |
| US-03 | 作为一个 **学生**，我想要 **创建自定义任务清单对任务分类**，以便 **按学科或类型管理学习内容**。 |
| US-04 | 作为一个 **学生**，我想要 **修改任务状态（待办/进行中/已完成/已取消）**，以便 **实时跟踪学习进度**。 |
| US-05 | 作为一个 **学生**，我想要 **为任务设置提醒时间并开启/关闭提醒**，以便 **不会错过重要的学习任务**。 |
| US-06 | 作为一个 **学生**，我想要 **查看学习统计报表（总任务数、完成数、完成率）**，以便 **了解自己的学习表现**。 |
| US-07 | 作为一个 **学生**，我想要 **维护个人账户信息**，以便 **安全地使用系统**。 |

---

## 3. 功能需求

### 3.1 任务管理

| 需求ID | 描述 | 优先级 |
|--------|------|--------|
| FR-01 | **创建任务**：用户可新增学习任务，必填字段包括任务名称、所属清单、截止时间；选填字段包括任务描述、优先级。 |
| FR-02 | **设置优先级**：系统支持为任务设置高、中、低三个优先级等级，用于排序和筛选。 |
| FR-03 | **更新任务状态**：用户可将任务状态修改为待办、进行中、已完成、已取消四种状态之一。 |
| FR-04 | **删除任务**：用户可删除不再需要的任务。 |
| FR-05 | **任务清单管理**：用户可创建、编辑、删除自定义任务清单（如"专业课""英语""刷题"等）。 |
| FR-06 | **任务筛选与排序**：用户可按清单、优先级、状态筛选任务；可按截止时间或优先级排序任务列表。 |

### 3.2 提醒管理

| 需求ID | 描述 | 优先级 |
|--------|------|--------|
| FR-07 | **设置提醒策略**：用户可为单个任务配置提醒时间（如截止前1小时/1天）。 |
| FR-08 | **开关提醒**：用户可独立开启或关闭每个任务的提醒功能。 |
| FR-09 | **接收提醒通知**：系统在提醒时间向用户发送通知。 |

### 3.3 学习统计

| 需求ID | 描述 | 优先级 |
|--------|------|--------|
| FR-10 | **任务统计概览**：用户可查看总任务数、已完成任务数、进行中任务数、任务完成率。 |
| FR-11 | **优先级分布统计**：用户可查看高/中/低优先级任务的数量分布。 |

### 3.4 用户账户

| 需求ID | 描述 | 优先级 |
|--------|------|--------|
| FR-12 | **用户注册与登录**：用户可通过用户名/密码注册并登录系统。 |
| FR-13 | **用户信息维护**：用户可修改个人基本信息（如用户名、密码）。 |
| FR-14 | **数据隔离**：用户只能查看和管理自己创建的任务数据。 |

---

## 4. 非功能需求

| 需求ID | 类别 | 描述 |
|--------|------|------|
| NFR-01 | **性能** | 系统应在3秒内完成页面响应；单个任务操作的响应时间不超过1秒。 |
| NFR-02 | **易用性** | 界面简洁直观，核心功能操作不超过3步即可完成；提供清晰的操作引导和反馈提示。 |
| NFR-03 | **安全性** | 用户密码需加密存储；用户会话需有效管理；不同用户数据严格隔离。 |
| NFR-04 | **可扩展性** | 采用模块化、分层架构设计，便于后续扩展重复任务、标签管理、日历视图等功能。 |
| NFR-05 | **可靠性** | 保障用户任务数据不丢失；系统具备基本的数据备份与恢复能力。 |
| NFR-06 | **兼容性** | 支持主流浏览器（Chrome、Edge、Firefox）正常访问。 |

## 5. 可测试的验收标准

| 验收ID | 验收标准 | 测试方法 |
|--------|----------|----------|
| AC-01 | **任务创建**：用户输入有效的任务名称、选择清单、设置截止时间后，系统成功创建任务并显示在任务列表中。 | 创建任务后验证列表中是否出现该任务。 |
| AC-02 | **优先级设置**：为任务设置高优先级后，该任务应在按优先级排序时排在最前面。 | 设置不同优先级后排序验证。 |
| AC-03 | **状态流转**：任务状态可从"待办"修改为"进行中"，再修改为"已完成"，状态更新即时生效。 | 修改状态后刷新页面验证状态是否正确。 |
| AC-04 | **任务清单分类**：用户可创建新清单"英语"，并将已有任务移入该清单，任务按清单筛选时可正确显示。 | 创建清单、迁移任务、按清单筛选验证。 |
| AC-05 | **提醒功能**：为任务设置提醒时间后，在到达提醒时间时系统应发送通知提醒用户。 | 设置短时提醒，等待并验证是否收到通知。 |
| AC-06 | **统计报表**：当用户有10个任务其中5个已完成时，统计页面应显示总任务数=10、已完成=5、完成率=50%。 | 创建指定数量任务后查看统计结果。 |
| AC-07 | **数据隔离**：使用用户A的账号登录后，无法查看或操作用户B创建的任务。 | 登录不同账号验证数据访问权限。 |
| AC-08 | **用户认证**：使用正确用户名和密码可成功登录；使用错误密码登录时系统拒绝访问。 | 输入正确/错误凭据验证登录结果。 |

# 接口契约说明

## 一、TaskApplicationService 接口

### 1.1 createTask

**功能**：创建新任务

**参数**：
```javascript
{
  userId: string,        // 用户ID（必填）
  name: string,          // 任务名称（必填）
  description?: string,  // 任务描述（可选）
  taskListId?: string,   // 任务列表ID（可选）
  dueDate?: Date,        // 截止日期（可选）
  priority?: string      // 优先级（可选，默认 MEDIUM）
}
```

**返回值**：`Promise<Task>` - 创建的任务实体

**业务规则**：
- userId 不能为空
- name 不能为空
- priority 有效值：HIGH, MEDIUM, LOW

**错误**：
| 错误信息 | 条件 |
|----------|------|
| userId 不能为空 | userId 为空 |
| title 不能为空 | name 为空 |

---

### 1.2 completeTask

**功能**：完成任务

**参数**：
```javascript
{
  taskId: string  // 任务ID（必填）
}
```

**返回值**：`Promise<Task>` - 更新后的任务实体

**业务规则**：
- 已取消的任务不可完成
- 已完成的任务重复调用返回原任务（幂等）

**错误**：
| 错误信息 | 条件 |
|----------|------|
| taskId 不能为空 | taskId 为空 |
| 任务不存在 | 任务ID不存在 |

---

### 1.3 getTask

**功能**：获取单个任务

**参数**：
```javascript
{
  id: string  // 任务ID
}
```

**返回值**：`Promise<Task | null>`

---

### 1.4 listTasksByUser

**功能**：获取用户的所有任务

**参数**：
```javascript
{
  userId: string  // 用户ID
}
```

**返回值**：`Promise<Task[]>`

---

### 1.5 listTasksByPriority

**功能**：获取用户任务并按优先级排序

**参数**：
```javascript
{
  userId: string  // 用户ID
}
```

**返回值**：`Promise<Task[]>` - 按优先级高到低排序

---

### 1.6 getTasksByFilters

**功能**：按条件筛选任务

**参数**：
```javascript
{
  userId: string,                    // 用户ID
  status?: string,                   // 状态筛选（可选）
  priority?: string,                 // 优先级筛选（可选）
  dueDateBefore?: Date,              // 截止日期早于（可选）
  includeCompleted?: boolean         // 是否包含已完成（默认 false）
}
```

**返回值**：`Promise<Task[]>`

---

### 1.7 deleteTask

**功能**：删除任务

**参数**：
```javascript
{
  id: string  // 任务ID
}
```

**返回值**：`Promise<boolean>` - 是否删除成功

---

## 二、TagApplicationService 接口

### 2.1 createTag

**功能**：创建标签

**参数**：
```javascript
{
  name: string  // 标签名称（必填）
}
```

**返回值**：`Promise<Tag>`

**错误**：
| 错误信息 | 条件 |
|----------|------|
| 标签名称不能为空 | name 为空 |

---

### 2.2 getTag

**功能**：获取标签

**参数**：
```javascript
{
  id: string  // 标签ID
}
```

**返回值**：`Promise<Tag | null>`

---

### 2.3 getAllTags

**功能**：获取所有标签

**返回值**：`Promise<Tag[]>`

---

### 2.4 addTagToTask

**功能**：为任务添加标签

**参数**：
```javascript
{
  taskId: string,  // 任务ID
  tagId: string    // 标签ID
}
```

**返回值**：`Promise<TaskTag>`

---

### 2.5 getTasksByTag

**功能**：按标签筛选任务

**参数**：
```javascript
{
  tagId: string  // 标签ID
}
```

**返回值**：`Promise<Task[]>`

---

### 2.6 removeTagFromTask

**功能**：从任务移除标签

**参数**：
```javascript
{
  taskId: string,  // 任务ID
  tagId: string    // 标签ID
}
```

**返回值**：`Promise<boolean>`

---

### 2.7 deleteTag

**功能**：删除标签（同时移除所有任务关联）

**参数**：
```javascript
{
  id: string  // 标签ID
}
```

**返回值**：`Promise<boolean>`

---

## 三、ReminderService 接口

### 3.1 getAllPendingReminders

**功能**：获取所有待处理提醒

**参数**：无

**返回值**：`Reminder[]` - 包含任务和策略信息的提醒列表

```javascript
{
  task: Task,           // 关联任务
  policy: object,      // 提醒策略配置
  strategyType: string // 策略类型
}
```

---

## 四、数据契约

### 4.1 Task 对象结构

```javascript
{
  id: string,
  name: string,
  description: string,
  taskListId: string,
  dueDate: Date | null,
  priority: {
    level: 'HIGH' | 'MEDIUM' | 'LOW',
    label: string,
    value: number
  },
  status: {
    state: 'PENDING' | 'IN_PROGRESS' | 'COMPLETED' | 'CANCELLED',
    label: string
  },
  completedAt: Date | null,
  createdAt: Date,
  updatedAt: Date
}
```

### 4.2 Tag 对象结构

```javascript
{
  id: string,
  name: string,
  createdAt: Date
}
```

### 4.3 优先级枚举

| 值 | level | label | value |
|----|-------|-------|-------|
| 高 | HIGH | 高优先级 | 3 |
| 中 | MEDIUM | 中优先级 | 2 |
| 低 | LOW | 低优先级 | 1 |

### 4.4 状态枚举

| 值 | state | label |
|----|-------|-------|
| 待办 | PENDING | 待办 |
| 进行中 | IN_PROGRESS | 进行中 |
| 已完成 | COMPLETED | 已完成 |
| 已取消 | CANCELLED | 已取消 |

---

## 五、错误处理约定

### 5.1 错误格式

所有业务异常抛出 `Error` 对象，错误消息使用中文：

```javascript
throw new Error('具体错误描述');
```

### 5.2 常见错误

| 场景 | 错误消息 |
|------|----------|
| 必填字段为空 | `xxx 不能为空` |
| 资源不存在 | `xxx 不存在` |
| 业务规则违反 | `已取消的任务不可完成` |
| 未知提醒类型 | `Unknown reminder type: xxx` |

## 3. 问题详情

### 问题 1：TaskStatus 字面量不一致

**位置**：TaskApplicationService.js 第 18、53 行

**问题**：重构后直接使用硬编码字面量，导致 TaskStatus 枚举失去意义

**修复**：
```javascript
const TaskStatus = require('../../domain/model/vo/TaskStatus');
status: TaskStatus.PENDING,
status: TaskStatus.COMPLETED,
```

---

### 问题 2：completeTask 逻辑与 Task.complete() 不一致

**位置**：TaskApplicationService.js vs Task.js

**问题**：
1. completeTask 未检查 CANCELLED 状态
2. completeTask 未设置 updatedAt
3. 两处状态赋值方式不一致

**修复**：
```javascript
// TaskApplicationService.completeTask()
async completeTask(taskId) {
  const task = await this.taskRepository.findById(taskId);
  if (!task) { throw new Error('任务不存在'); }
  task.complete();  // 使用实体的状态模式方法
  return this.taskRepository.save(task);
}
```
